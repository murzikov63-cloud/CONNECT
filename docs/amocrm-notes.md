# amoCRM: как получаем доступ к Chat API (amojo)

Проверено 2026-08-18 по официальной документации amoCRM
(https://www.amocrm.ru/developers/content/chats/chat-start и .../chats/chat-api).

## Главный вывод

Доступ к API чатов **выдаётся по заявке в техподдержку amoCRM**.
Статус партнёра/интегратора **не требуется** — в документации таких ограничений нет.
Про платность в документации не сказано ничего.

- Срок рассмотрения заявки: **1–3 рабочих дня**.
- Канал создаётся **приватным** — работает только на явно перечисленных в заявке
  аккаунтах. Это ровно наш случай (один аккаунт Анатолия).
- Позже канал можно перевести в публичный (нам не нужно).
- Способ подачи: из аккаунта amoCRM в техподдержку, либо через их страницы в соцсетях.
- В ответ приходят `channel_id` и `secret_key` + подтверждение списка аккаунтов.

## Что обязательно указать в заявке (16 пунктов)

1. Название сервиса — латиница, не начинается с цифры
2. Webhook URL в формате `https://domain.com/location/:scope_id` (подстановка динамическая)
3. Список ID аккаунтов, где канал разрешён на старте
4. Поддержка «Написать первым» — да/нет
5. Поддержка временного окна — есть/нет, длительность в секундах, показ шаблонов после окончания
6. Email для связи при ошибках
7. SVG-иконка: круглая, 14×14 px, до 100 КБ
8. `client_uuid` интеграции
9. Код виджета из «Ключи и доступы» (опционально)
10. Планы тиражирования на всех пользователей
11. Логика хранения загруженных файлов
12. Поддержка реакций (если частично — список эмодзи)
13. Цитирование сообщений — да/нет
14. Голосовые сообщения — да/нет
15. Доступность в Kommo — да/нет
16. Хуки о печатании (typing) — да/нет

## Дальше по технике

- Подключение канала к аккаунту: `POST /v2/origin/custom/{channel_id}/connect`,
  в теле — `amojo_id` аккаунта, в ответе — `scope_id`.
- Подпись запросов: заголовки `Date`, `Content-Type`, `Content-MD5`, `X-Signature`
  (HMAC-SHA1 от строки запроса на `secret_key`).
- `scope_id` подставляется в наш webhook URL — по нему различаем аккаунт.

## Порядок действий

`client_uuid` берётся из приватной интеграции в amoCRM, поэтому интеграцию надо
создать ДО отправки заявки. Инструкция: `anatoly/01-integration-howto.md`.
