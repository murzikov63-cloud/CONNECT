# Шаг 2. Письмо в техподдержку amoCRM

**Куда:** из аккаунта amoCRM → значок поддержки (правый нижний угол) → написать в чат.
Можно приложить файл — приложите `icon.svg` из этой же папки.

**Перед отправкой заполните три места, помеченные ➜.** Остальное уже готово.

---

Здравствуйте!

Просим зарегистрировать канал для API чатов (amojo) для нашей приватной интеграции.
Ниже все данные по вашему списку.

1. Название сервиса: Messenger
2. Webhook URL: https://connect.indolight.com/amojo/:scope_id
3. ID аккаунтов для работы на начальном этапе: ➜ УКАЖИТЕ ID ВАШЕГО АККАУНТА
4. Поддержка «Написать первым»: да
5. Поддержка временного окна: нет, окно не ограничено
6. Email для связи при ошибках: ➜ УКАЖИТЕ ПОЧТУ
7. SVG-иконка: приложена к обращению (круглая, 14×14, 1 КБ)
8. client_uuid интеграции: ➜ ВСТАВЬТЕ ID ИНТЕГРАЦИИ ИЗ ШАГА 1
9. Код виджета: не используется, интеграция без виджета
10. Тиражирование на всех пользователей: не планируется, канал нужен приватным
    только для перечисленных выше аккаунтов
11. Хранение файлов: файлы храним на своей стороне и отдаём в amoCRM
    по прямым ссылкам, срок хранения — 180 дней
12. Поддержка реакций: нет
13. Цитирование сообщений: да
14. Голосовые сообщения: да
15. Доступность в Kommo: нет
16. Хуки о печатании (typing): нет

Просим прислать channel_id и secret_key. Спасибо!

---

## Чего ждать

Ответ по документации — **1–3 рабочих дня**. В ответе будут `channel_id` и
`secret_key` — пришлите их мне, и я подключу канал к аккаунту.
